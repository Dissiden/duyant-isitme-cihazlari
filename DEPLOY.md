# Canlıya Alma Kontrol Listesi

## Local
- `npm install`
- `npm run build`
- Ana sayfa, mobil menü, slider, WhatsApp ve harita kontrolü

## GitHub
- Yeni repo: `duyant-isitme-cihazlari`
- Tüm proje dosyalarını push et

## Vercel
- Repo import
- Deploy
- Preview URL'de test

## Domain
- `isitmecihaziantalya.com`
- `www.isitmecihaziantalya.com`
- DNS değerleri için Vercel Dashboard'da gösterilen kayıtları birebir uygula
- Root domaini primary yap
- www → root yönlendirmesi

## SEO
- Search Console doğrulama
- `/sitemap.xml` gönder
- `/robots.txt` kontrol
- Ana sayfanın canonical etiketi root domaine işaret etmeli
- Google Business Profile website alanını güncelle
